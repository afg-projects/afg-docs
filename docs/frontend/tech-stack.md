# 技术栈详解

前端项目采用现代化的技术栈，提供出色的开发体验和用户体验。

## 核心技术

### React 18

- **并发特性**：支持 Suspense、Transitions 等并发特性
- **自动批处理**：自动合并状态更新
- **Strict Mode**：开发环境下的严格模式检查

### TypeScript 5.x

- **类型安全**：编译时类型检查
- **智能提示**：IDE 自动补全和类型推断
- **类型推导**：强大的类型推导能力

### Vite 6.x

- **极速启动**：基于 ESM 的开发服务器
- **热更新**：毫秒级的热模块替换
- **优化构建**：基于 Rollup 的生产构建

## UI 框架

### Ant Design 5

- **组件丰富**：60+ 高质量组件
- **设计规范**：企业级设计语言
- **主题定制**：CSS-in-JS 主题方案
- **国际化**：内置多语言支持

## 状态管理

### Zustand

- **轻量级**：极小的包体积
- **简单 API**：直观的状态管理
- **TypeScript 友好**：完整的类型支持
- **中间件**：持久化、日志等中间件

## 包管理

### pnpm 10

- **高效存储**：硬链接节省磁盘空间
- **严格依赖**：避免幽灵依赖
- **工作空间**：原生 monorepo 支持
- **快速安装**：比 npm/yarn 更快

## 微前端

### qiankun 2.10

- **框架无关**：支持任意前端框架
- **样式隔离**：自动隔离子应用样式
- **JS 沙箱**：隔离子应用 JS 执行
- **资源预加载**：提升子应用加载速度
