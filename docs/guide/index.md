# 介绍

灵蛙企业级应用平台是一个现代化的企业级应用开发框架，包含前端、后端和基础框架三个核心项目。

## 项目组成

| 项目 | 技术栈 | 说明 |
|------|--------|------|
| **afg-frontend** | React 18 + TypeScript + pnpm monorepo + qiankun | 灵蛙企业级应用平台前端 |
| **afg-backend** | Java 25 + Spring Boot 4 + Gradle | 业务后端服务 |
| **afg-framework** | Java 25 + Spring Boot 4 + Gradle | 企业级 Java 开发框架（基础库） |

## 核心特性

### 前端

- **React 18** - 最新的 React 版本，支持并发特性
- **TypeScript** - 类型安全，提升开发体验
- **Vite** - 极速的开发服务器和构建工具
- **Ant Design 5** - 企业级 UI 组件库
- **pnpm monorepo** - 高效的包管理和工作空间
- **qiankun** - 微前端解决方案

### 后端

- **Java 25** - 最新的 Java LTS 版本
- **Spring Boot 4** - 现代化的 Spring 应用开发
- **Spring Cloud Alibaba** - 微服务解决方案
- **Gradle** - 灵活的构建工具

### 框架

- **核心模块** - 缓存、事件、异常、安全、调度
- **数据访问** - JDBC 增强、SQL 构建器、Liquibase 迁移
- **中间件集成** - Redis、Kafka、RabbitMQ、WebSocket、OSS 等
